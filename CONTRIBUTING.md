# Contribution & Engineering Guidelines

Este portfólio segue um fluxo simples, próximo ao usado em times de produto.

1. Crie uma branch descritiva.
2. Faça mudanças pequenas e focadas.
3. Rode build, TypeScript e testes do projeto alterado.
4. Verifique responsividade e acessibilidade básica.
5. Atualize o README quando necessário.
6. Abra Pull Request usando o checklist do repositório.
7. Só integre mudanças após os checks automáticos passarem.

## Definition of Done

Uma alteração está pronta quando compila, não introduz erro conhecido, mantém navegação utilizável por teclado, possui documentação coerente e passa pelos checks relevantes de CI.
