## Como documento um chamado

Cada exercício é registrado seguindo uma estrutura próxima da rotina de suporte:

**Problema → Impacto → Diagnóstico → Testes realizados → Causa → Solução → Validação**

Exemplo:

> **Problema:** usuário sem acesso à internet.  
> **Diagnóstico:** verificação de configuração com `ipconfig`, teste de gateway com `ping` e validação de resolução DNS com `nslookup`.  
> **Causa simulada:** servidor DNS configurado incorretamente.  
> **Solução:** correção da configuração de DNS e novo teste de conectividade.  
> **Validação:** acesso à rede e resolução de nomes normalizados.
