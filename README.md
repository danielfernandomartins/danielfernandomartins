## 🧠 Método de troubleshooting

1. Entender o impacto para o usuário.
2. Reproduzir ou confirmar o sintoma.
3. Coletar evidências antes de alterar configurações.
4. Começar pelos testes mais simples e seguros.
5. Isolar a causa provável.
6. Aplicar a correção apropriada.
7. Validar com o usuário ou por teste técnico.
8. Documentar a resolução.
9. Escalar quando estiver fora do escopo N1.
