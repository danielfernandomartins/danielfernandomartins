# Laboratório 04 — Microsoft 365

## Objetivo

Praticar cenários comuns de suporte ao usuário em ferramentas Microsoft 365.

## Cenários para estudar

### Outlook não sincroniza

Checklist:

1. Confirmar conexão com a internet.
2. Verificar se o serviço está acessível pelo navegador.
3. Confirmar credenciais e autenticação.
4. Verificar mensagens de erro.
5. Conferir modo offline.
6. Reiniciar o aplicativo.
7. Registrar evidências antes de ações mais invasivas.

### Teams sem áudio

Checklist:

- verificar dispositivo de entrada e saída;
- validar permissões de microfone;
- testar outro aplicativo;
- verificar dispositivo padrão do Windows;
- executar chamada de teste quando disponível.

### OneDrive não sincroniza

Checklist:

- verificar login;
- verificar conectividade;
- verificar espaço disponível;
- identificar arquivos com erro de sincronização;
- revisar caracteres ou nomes inválidos quando aplicável.

## Registro da prática

Para cada cenário executado, registrar:

**Sintoma → diagnóstico → testes → solução → validação.**
