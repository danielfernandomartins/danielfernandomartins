# Laboratórios de Suporte de TI

Este diretório registra práticas voltadas à rotina de **Help Desk, Service Desk e Suporte Técnico N1**.

O objetivo não é apenas listar tecnologias estudadas, mas demonstrar raciocínio de troubleshooting e documentação.

## Laboratórios

1. [Windows e troubleshooting](01-windows-troubleshooting.md)
2. [Diagnóstico de rede](02-network-diagnostics.md)
3. [Active Directory](03-active-directory.md)
4. [Microsoft 365](04-microsoft-365.md)
5. [Service Desk e chamados](05-service-desk.md)

## Padrão de documentação

Cada exercício deve registrar:

- Problema apresentado
- Impacto para o usuário
- Hipóteses iniciais
- Ferramentas/comandos utilizados
- Diagnóstico
- Solução aplicada
- Validação final
- Aprendizado

> Importante: os cenários deste portfólio são laboratórios e simulações de estudo. Eles não devem ser apresentados como experiência profissional real.
