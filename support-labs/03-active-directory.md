# Laboratório 03 — Active Directory

## Objetivo

Entender tarefas básicas de suporte em ambientes com domínio Windows.

## Tarefas para praticar

- criar usuário;
- redefinir senha;
- desbloquear conta;
- criar grupos;
- adicionar e remover usuários de grupos;
- compreender OU (Organizational Unit);
- diferenciar usuário local de usuário de domínio;
- validar permissões de acesso.

## Cenário — Usuário não consegue entrar no computador

**Problema:** usuário informa que a senha não funciona.

### Diagnóstico sugerido

1. Confirmar se o usuário está tentando entrar no domínio correto.
2. Verificar se a conta está bloqueada.
3. Verificar se a senha expirou.
4. Redefinir a senha quando necessário e autorizado.
5. Solicitar troca no próximo logon quando apropriado.
6. Validar acesso.

## Registro da prática

Preencher após executar o laboratório:

- ambiente utilizado;
- usuário criado;
- grupo utilizado;
- problema reproduzido;
- ação executada;
- resultado final.

## Conceitos importantes

- domínio;
- controlador de domínio;
- usuário e grupo;
- OU;
- autenticação;
- permissões;
- princípio do menor privilégio.
