## Princípio deste material

O objetivo não é repetir documentação nem criar uma lista de buzzwords. Cada nota responde a quatro perguntas:

1. **O que mudou?**
2. **Por que isso importa em produto?**
3. **Que trade-offs existem?**
4. **Como eu aplicaria em um projeto Front-End?**

As fontes primárias ficam no final de cada nota.
