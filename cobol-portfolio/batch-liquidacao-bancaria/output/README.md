# Saídas do processamento

Este diretório recebe os arquivos gerados pelo programa batch quando executado localmente:

- `rejeitados.txt` — registros recusados pelas validações;
- `resumo.txt` — quantidade de válidos/rejeitados e total financeiro processado.

Os arquivos são gerados em runtime e não representam dados reais de clientes ou transações bancárias.
