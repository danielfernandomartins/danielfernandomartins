# PowerShell para Suporte N1

Scripts simples e seguros para coleta de informações durante troubleshooting.

## Objetivo

Demonstrar automação básica sem esconder o raciocínio de suporte. Os scripts desta pasta são voltados principalmente a **leitura e diagnóstico**.

## Scripts

- [Coleta básica da estação](collect-system-info.ps1)

## Princípios

- priorizar comandos não destrutivos;
- entender o que cada comando faz;
- registrar a saída relevante no chamado;
- não executar scripts administrativos em ambiente real sem autorização.
