# 📊 Data Analyst Portfolio

Dois cases simples e objetivos para demonstrar competências cobradas em vagas iniciais de **Analista de Dados / BI**.

## 1. Análise Comercial com SQL

Case focado em consultas SQL e KPIs de vendas.

**Demonstra:** `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `SUM`, `AVG`, `COUNT`, leitura de receita, ticket médio, desempenho por vendedor e categoria.

➡️ [Abrir projeto](./vendas-sql)

## 2. Customer KPIs com Python + Pandas

Case focado em análise de carteira, indicadores de clientes e segmentação simples de risco de churn.

**Demonstra:** Pandas, filtros, agregações, variáveis derivadas, segmentação, exportação CSV e preparação de dados para Excel/Power BI.

➡️ [Abrir projeto](./customer-kpis-python)

## Competências cobertas

- SQL
- Python
- Pandas
- CSV
- KPIs
- análise de clientes
- análise comercial
- preparação para Power BI / Excel
- comunicação de insights

Os dados são sintéticos e os projetos foram mantidos propositalmente simples para que o foco fique em raciocínio analítico, qualidade da consulta e interpretação de negócio.
