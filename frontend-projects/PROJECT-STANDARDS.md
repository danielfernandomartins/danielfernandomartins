# Padrão de qualidade dos projetos Front-End

Todos os projetos desta trilha devem buscar os mesmos critérios:

- **Semântica:** HTML e componentes com estrutura clara.
- **Responsividade:** uso confortável em desktop e mobile.
- **Acessibilidade:** labels, foco visível, teclado e mensagens compreensíveis.
- **TypeScript:** `strict: true` nos projetos TypeScript.
- **Estados de UI:** loading, erro, vazio e sucesso quando aplicável.
- **Organização:** nomes legíveis e responsabilidade clara dos componentes.
- **Dados:** nunca versionar credenciais ou dados reais de clientes.
- **Qualidade:** build automatizado; testes onde agregam valor.
- **Documentação:** objetivo, stack, execução e pontos para entrevista.
- **Recrutador:** cada projeto deve provar uma competência específica, evitando repetição sem propósito.
